How the trench board works

Every FBS roster's offensive-line and defensive-line average weights are computed from current-season rosters. For each game, each offense gets a trench edge: its OL average minus the opposing DL average, centered against the league-wide norm (offensive lines naturally run heavier than defensive fronts, so raw differences mislead — the centering is what made the backtest ladder appear). Edges are quintile-ranked against the full season's matchup set. Top-quintile edges become RUSH EDGE targets; when the kickoff forecast shows 15+ mph wind outdoors — the scripts that lean run-heavy — they upgrade to STACKED RUSH. Bottom-quintile edges become RUSH FADE flags. Weather joins from the same forecast engine as the free CFB radar. A top-quintile edge only becomes a rushing-prop TARGET if the offense actually runs the ball (pass-first teams — under a 44% run rate last season — stay on the board but never get flagged: real edge, wrong market). Each lean names the team's top returning rusher from last season's production, cross-checked against the current roster. Every lean is archived the moment it posts and graded publicly against actual rushing box scores — a TARGET hits when the team beats that week's FBS median yards per carry, a FADE hits when it lands below it, so a league-wide sloppy week can't fake our record either way — same receipts-first rules as every DFSRADAR board. We validated this signal for rushing output only; our backtest found no reliable edge for sides or totals, so this board makes no such claims. Tendencies, not guarantees.
